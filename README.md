🚀 Xygred0 Portfolio & Support Center
Bienvenue sur le dépôt officiel du projet Xygred0 Shadowbyte. Ce site est un portfolio interactif combinant une présentation de services, un showcase de compétences et un centre d'aide utilisateur complet.

📋 Présentation du Projet
Ce projet est conçu pour offrir une expérience utilisateur fluide et moderne. Il permet non seulement de découvrir le profil de Faissate Xygred, mais propose aussi des outils intégrés comme un testeur de code et une application météo.

Fonctionnalités Clés :
.Design Responsive : Adapté aux mobiles, tablettes et ordinateurs.

.Mode Sombre/Clair : Interface ajustable pour le confort visuel.

.Centre d'Aide Interactif : Une section FAQ avec système d'accordéon dynamique (JavaScript).

.Outils Intégrés : Liens vers un éditeur de code en temps réel et des sites partenaires.
🛠️ Technologies Utilisées
Le projet repose sur des technologies web standards pour garantir performance et accessibilité :
Technologie,Usage
HTML5,Structure sémantique du contenu.
CSS3,"Mise en page, animations et design personnalisé."
JavaScript,"Interactivité (FAQ, menu mobile, switch de mode)."
Unicons / Ionicons,Bibliothèques d'icônes vectorielles.
